# Hotel Dataset Manipulation & Feature Engineering

## 📌 Project Overview

In this project, I worked on a hotel booking dataset and performed **data manipulation and feature engineering** to make the data more useful for analysis and machine learning.

The main goal was to clean, transform, and organize the raw CSV data into a **final processed dataset**.

## 🎯 Objective

* Clean the raw dataset
* Combine data from multiple CSV files
* Create useful new features
* Remove unnecessary columns
* Handle missing values
* Convert data into a suitable format
* Export the final manipulated dataset as a CSV file

## 🔧 Data Manipulation Performed

Some of the transformations included:

* Extracting **Year, Month, and Week Number** from reservation dates
* Handling missing values
* Selecting required columns
* Renaming columns where required
* Converting data into appropriate formats
* Combining multiple CSV files
* Creating additional features such as **Extra Charges** and **Discount**
* Preparing the final dataset for further analysis or machine learning

## 📂 Dataset

The project uses hotel booking-related CSV files as the input data.

### Input

Multiple raw CSV files

### Output

A single cleaned and manipulated CSV dataset containing the required features.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook / Google Colab

## 📊 Final Dataset

The final dataset contains important features such as:

* `arrival_year`
* `arrival_month`
* `arrival_week_number`
* `lead_time`
* `adults`
* `children`
* `babies`
* `weekend_nights`
* `week_nights`
* `room_type_reserved`
* `market_segment`
* `distribution_channel`
* `avg_price_per_room`
* `Extra_Charges`
* `Discount`

## 🚀 Result

The raw hotel data was successfully transformed into a **clean and structured CSV dataset**, which can be used for further **EDA, visualization, and machine learning projects**.



This project helped me practice **Pandas, data cleaning, data manipulation, and feature engineering** using real-world data.
